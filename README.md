<h1>Todo App</h1>

<p>
  A task manager built with JavaScript, HTML, and CSS to help organize tasks by project.
</p>

<p><strong>Live demo:</strong> <a href="https://alexisjhay.github.io/todo-list/">View Todo App</a></p>

<h2>Features</h2>
<ul>
  <li>Create and delete projects (the Default project cannot be deleted)</li>
  <li>Add Todos with a title, description, due date, and priority</li>
  <li>Edit and delete Todos</li>
  <li>Mark Todos as complete</li>
  <li>Organize Todos by project</li>
  <li>Filter Todos by status, priority, and overdue tasks</li>
  <li>Save Todos and projects in localStorage, so data persists after page reloads</li>
  <li>Responsive layout for desktop, tablet, and mobile</li>
</ul>

<h2>Built with</h2>
<ul>
  <li>JavaScript (ES modules and classes)</li>
  <li>HTML</li>
  <li>CSS</li>
  <li>Webpack</li>
  <li>localStorage for data persistence</li>
</ul>

<h2>What I learned</h2>
<ul>
  <li>Using JavaScript classes to organize and manage project and Todo objects</li>
  <li>Splitting code into ES modules to keep different parts of the app organized</li>
  <li>Using localStorage to save and retrieve data with JSON.stringify() and JSON.parse()</li>
  <li>Working with DOM events and event delegation to handle user interactions</li>
  <li>Filtering and displaying Todos based on their project, completion status, priority, and due date</li>
  <li>Building a responsive layout with CSS</li>
</ul>
